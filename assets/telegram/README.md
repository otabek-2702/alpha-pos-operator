# Telegram profile assets

`bot-profile.jpg` is a JPEG copy of the existing mobile app icon, `../icon.png`. Its composition is unchanged. Telegram's `InputProfilePhotoStatic` requires a JPEG upload.

`call-center-source.jpg` is the original 640 × 640 Smart Food call-center avatar provided for this branding task. It contains the white crown, lettering, slogan, and curved lines on orange.

`recordings-profile.png` was edited with the built-in image generation tool. The selected revision retains the existing brand design and adds a separate microphone badge in the empty area below it. The source remains available for comparison. The generated raster is larger than the original; it is not a byte-identical copy of the source. `recordings-profile.jpg` is the JPEG format conversion for the recording group. The exact final prompt is saved in `recordings-profile.prompt.txt`.

`stats-profile.jpg` is an unchanged copy of the original source image for the reporting group.

API reference: [Telegram Bot API](https://core.telegram.org/bots/api#setmyprofilephoto).
